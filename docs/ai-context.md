# AI Context

KhanaLens is a mobile-first AI food nutrition analysis web app.

## Stack

React + Vite + JavaScript + React Compiler  
Node.js + Express  
MongoDB + Mongoose  
Gemini API

- Inspect existing code before creating new code.

- Keep changes focused on the requested task.
