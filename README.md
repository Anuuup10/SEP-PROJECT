# KhanaLens

KhanaLens is an AI powered mobile based web application that helps users understand what they eat. Users can scan or upload food images, receive AI-generated food and nutrition estimates, save meals, view meal history, track progress, and manage nutrition goals.

> **Disclaimer:** Nutrition information generated by KhanaLens is an estimate based on food images and AI analysis. It should not be considered medical advice or a replacement for guidance from a qualified nutritionist or healthcare professional.

## Live Demo

[Click here to view the live application](https://khana-lens.vercel.app/)
## Features

- User registration, login, and logout
- Firebase Authentication
- Google sign-in support
- Food image capture using the device camera
- Food image upload
- AI-powered food identification using Google Gemini
- Detection of multiple food items in a single meal
- Estimated portions and cooking methods
- Nutrition estimates including:
  - Calories
  - Protein
  - Carbohydrates
  - Fat
  - Fiber
  - Sugar
  - Saturated fat
  - Sodium
- Meal analysis summaries
- Individual food detail views
- Save analyzed meals
- Meal history
- Daily and Weekly nutrition progress
- Nutrition goal management
- AI-generated meal plans
- Profile and settings management
- Mobile bottom navigation
- Responsive mobile, tablet, and desktop layouts

## Prerequisites

Install the following before running the project:

- Node.js 18 or newer
- npm
- A Firebase project
- Firebase Authentication enabled
- Firebase Firestore enabled
- Firebase Storage enabled if profile image uploads are required
- A Google Gemini API key
- Firebase web application configuration
- Firebase Admin service-account credentials

## Installation

Clone the repository and enter the project directory:

```bash
git clone <repository-url>
cd SEP-PROJECT
```

Install all project dependencies:

```bash
npm run install:all
```

Alternatively, install dependencies separately:

```bash
npm install
npm install --prefix client
npm install --prefix server
```

## Environment Configuration

### Client environment variables

Create a file named `.env` inside the `client/` directory:

```env
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_firebase_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_firebase_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
VITE_FIREBASE_APP_ID=your_firebase_app_id
```

The frontend uses these values for Firebase Authentication and Google sign-in.

### Server environment variables

Create a file named `.env` inside the `server/` directory:

```env
PORT=5000
JWT_SECRET=replace_with_a_secure_secret
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-3.5-flash-lite

FIREBASE_PROJECT_ID=your_firebase_project_id
FIREBASE_CLIENT_EMAIL=your_firebase_service_account_email
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nYOUR_PRIVATE_KEY\n-----END PRIVATE KEY-----\n"
FIREBASE_STORAGE_BUCKET=your_firebase_storage_bucket
```

A Firebase service-account JSON file may also be used. If using that option, set:

```env
FIREBASE_SERVICE_ACCOUNT_PATH=firebase-service-account.json
```

Do not commit `.env` files, Firebase service-account files, private keys, or API keys to Git.

## Running the Application

### Run frontend and backend together

From the project root:

```bash
npm run dev
```

### Run only the frontend

```bash
npm run client
```

### Run only the backend

```bash
npm run server
```

## Data and Privacy

KhanaLens stores application data in Firebase Firestore, including:

- User profiles
- Nutrition goals
- Food scan results
- Saved meals
- Meal-plan information
- Progress data

Profile images may be stored in Firebase Storage.
Users should not upload sensitive medical documents or private information as food images.
