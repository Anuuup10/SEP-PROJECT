# Design & UX Guidelines

## Theme & Aesthetic
- **Visual Style**: Modern, clean, dark glassmorphism design system.
- **Primary Color Palette**:
  - Background: `#090d16` (Deep Obsidian dark mode)
  - Surface Glass: `rgba(255, 255, 255, 0.05)` with `backdrop-filter: blur(16px)`
  - Accent Emerald: `#10b981` (Health / Calories)
  - Accent Cyan: `#06b6d4` (Protein)
  - Accent Violet: `#8b5cf6` (Carbs & Fats)
- **Typography**: Inter / Outfit sans-serif fonts.

## UI Components Structure
- **Navbar / Header**: Quick navigation, user profile avatar, scan button.
- **Scanner Modal**: Drag-and-drop file upload, live camera feed interface, loading animations during AI processing.
- **Macro Cards**: Interactive stat cards with animated hover glow effects.
